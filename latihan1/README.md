# Latihan - Klasifikasi Penyakit Jantung

 Project latihan ini menjadi bagian dari penerapan materi yang dipelajari melalui **Coursera**, khususnya tentang dasar-dasar Machine Learning dan proses membangun model klasifikasi, dan juga sudah dipelajari waktu Semester 3 mata kuliah Machine Learning

Pada project ini, saya menggunakan dataset kesehatan yang berisi beberapa informasi pasien seperti **usia, jenis kelamin, tekanan darah, kolesterol, detak jantung, dan faktor kesehatan lainnya**. Data tersebut digunakan untuk memprediksi apakah seseorang terindikasi penyakit jantung atau tidak.

Model yang digunakan adalah **Logistic Regression**. Sebelum model dilatih, data dibersihkan, dipisahkan menjadi data training dan testing, kemudian dilakukan **standardisasi data**.

## Yang Dipelajari

- Memahami data dan fitur yang digunakan.
- Melakukan data cleaning.
- Membagi data menjadi training dan testing.
- Melakukan standardisasi data.
- Membangun model **Logistic Regression**.
- Mengevaluasi model menggunakan **accuracy**.

Project ini menjadi contoh sederhana bagaimana konsep Machine Learning yang dipelajari di Coursera diterapkan langsung menggunakan Python dan Scikit-learn.
